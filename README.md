# 📝 To-Do App

A responsive web-based To-Do List application built using Flask, HTML, CSS, and SQLite.

This application allows users to:

* Add tasks
* Mark tasks as completed
* Delete tasks
* Manage daily activities efficiently

---

## 🚀 Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Responsive UI for desktop and mobile
* Attractive multicolor background
* Interactive user interface
* SQLite database integration

---

## 🛠️ Tech Stack

### Frontend

* HTML5
* CSS3
* JavaScript

### Backend

* Python
* Flask

### Database

* SQLite
