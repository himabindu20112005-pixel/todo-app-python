# 📝 To-Do App

A **responsive web-based To-Do List application** built using **Flask, HTML, CSS, and SQLite**.  
This app allows users to **add, complete, and delete tasks** in a clean and interactive interface.

---

## 🔹 Features

- Add new tasks  
- Mark tasks as completed  
- Delete tasks  
- Responsive design for mobile and desktop  
- Attractive multicolor background  
- Easy-to-use and interactive UI

---

## 🔹 Tech Stack

- **Backend:** Python (Flask)  
- **Frontend:** HTML, CSS  
- **Database:** SQLite
